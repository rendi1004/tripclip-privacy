TripClip 개인정보처리방침

최종 업데이트: 2026년 10월 22일

TripClip(“앱”)은 여행의 순간을 기록하는 앱입니다. 계정이 없고, 기록한 내용은 원칙적으로 사용자 기기에만 저장됩니다. 앱은 이름·이메일·전화번호 같은 계정 정보를 수집하지 않습니다.

이 문서는 앱의 실제 동작을 그대로 적은 것입니다. 무엇이 기기 밖으로 나가고 무엇이 나가지 않는지가 핵심이므로, 그 둘을 먼저 나누어 적습니다.

사진·동영상·여권 정보·메모는 위 어느 곳으로도 전송되지 않습니다. 앱 운영자의 서버는 장소를 대신 물어 줄 뿐, 누가 물었는지(기기·계정)는 남기지 않습니다.

지도와 위치 관련 서비스는 좌표나 검색어를 받게 되므로, 각 서비스의 처리 방침이 함께 적용됩니다.

  • OpenStreetMap 재단(Nominatim): 개인정보처리방침
  • 카카오(카카오 로컬): 개인정보처리방침
  • Komoot(Photon): 개인정보처리방침
  • Google(지도·Places·Firebase·글꼴): 개인정보처리방침

3. 항공편 지연 알림 (선택 기능)

알림을 켜면 앱이 꺼져 있어도 지연을 알려주기 위해 다음을 앱 운영자의 서버에 등록합니다.

  • 기기 푸시 토큰(FCM)
  • 편명, 날짜, 방향(출국/입국), 공항 코드, 예정 출발 시각

여권번호·성명 등 개인 식별 정보는 서버로 전송되지 않습니다. 등록 정보는 3일 뒤 자동 삭제되며, 알림을 끄거나 해당 비행편을 지우면 즉시 해제됩니다. 이 기능을 쓰지 않으면 아무것도 등록되지 않습니다.

홈 화면에 ‘다음 비행편’ 위젯을 두면, 위젯이 출발 3시간 전부터 위의 정보(푸시 토큰·편명·날짜·방향)로 서버에 그 편의 지금 상태를 묻습니다. 새로 등록되는 정보는 없으며, 지연 알림을 꺼 두면 묻지 않습니다.

4. 프라이빗 잠금

여행이나 사진을 숨겨 두는 기능입니다.

  • PIN은 저장하지 않습니다. PBKDF2로 10만 회 늘린 해시와 무작위 salt만 기기의 보안 저장소에 보관하고, 확인할 때 같은 방식으로 늘려 비교합니다.
  • 지문·얼굴 인식을 쓰는 경우 생체 정보는 기기 운영체제가 처리하며, 앱은 성공/실패 결과만 받습니다. 앱은 생체 정보에 접근하지 않습니다.
  • 숨긴 항목은 기기 안에 그대로 있고, 어디로도 전송되지 않습니다.

5. 백업과 공유

  • 공유·내보내기: 사용자가 직접 버튼을 눌렀을 때만, 선택한 파일이 사용자가 고른 다른 앱으로 전달됩니다.
  • 여행 기록(PDF·PPT): 사용자가 만들기를 눌렀을 때 기기 안에서 만들어지고, 사용자가 고른 곳으로만 저장·공유됩니다. 여행 제목·일정, 사진, 함께 간 사람의 이름과 사진, 비행편·숙소, 지출이 담기며 여권 정보·연락처는 넣지 않습니다. 숨겨 둔 사진은 잠겨 있으면 빠집니다.
  • 백업: .tripbackup 파일은 사용자가 직접 보관합니다(기기 저장소, 클라우드 드라이브 등). 앱 운영자는 이 파일에 접근하지 않습니다.
  • 백업 파일에는 사진·동영상과 여권 정보를 푸는 암호화 키가 함께 들어 있어, 그 파일을 가진 사람은 내용을 볼 수 있습니다. 백업할 때 비밀번호를 걸면 파일 전체가 암호화됩니다(PBKDF2 10만 회 + AES). 백업 파일 보관은 사용자 책임입니다.

6. 보안

  • 여권·동행인·‘내 정보’ 등 민감한 항목은 기기 데이터베이스에 AES로 암호화해 저장합니다.
  • 암호화 키는 운영체제 보안 저장소(Android Keystore / iOS Keychain)에 보관합니다.
  • 앱과 서버 사이 통신은 HTTPS를 사용합니다.

7. 사용자의 권리와 삭제

  • 앱 안에서 언제든 여행·사진·동행인·준비물을 지울 수 있습니다.
  • 앱을 삭제하면 기기 안의 모든 데이터가 사라집니다. 따로 보관한 백업 파일은 사용자가 직접 지워야 합니다.
  • 지연 알림 서버 등록은 알림을 끄면 해제되고, 남아 있어도 3일 뒤 자동 삭제됩니다.

8. 광고와 추적

현재 버전의 TripClip은 광고를 보여주지 않으며, 제3자 광고·분석 추적 도구를 사용하지 않습니다. 사용자 행동을 수집해 분석하지 않습니다.

앞으로 광고나 분석 도구를 도입하게 되면 도입 전에 이 방침을 갱신하고, 어떤 사업자가 무엇을 수집하는지 여기에 적겠습니다.

9. 아동

앱은 만 13세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 알면서 수집하지 않습니다.

10. 변경 고지

이 방침이 바뀌면 이 문서의 ‘최종 업데이트’ 날짜를 갱신합니다.

11. 데이터 삭제

기록은 기기에만 있으므로 앱에서 직접 지울 수 있고, 앱을 삭제하면 전부 사라집니다. 자세한 방법과 요청 창구는 데이터 삭제 안내를 봐 주세요.
